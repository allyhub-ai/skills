# AllyHub skills

AllyHub skills are free Agent Skills for Claude Code, Codex and AllyHub Studio. Each one teaches your agent one kind of work, such as a product demo video, an explainer, a launch short or a list of people who need your product, and the agent makes it on your computer with AllyHub.

## Questions

### What is an Agent Skill?

A folder of instructions that an agent reads when a task calls for it, in the open [Agent Skills](https://agentskills.io) format that Claude Code, Codex and many other agents read.

### How do I use one?

Copy a skill's prompt into your agent. Or add the skill to your project's folder with `npx skills add https://allyhub.com --skill <name>`. In AllyHub Studio, pick it when you start a project.

### Do I need anything else?

The allyhub skill, which says how AllyHub works; each skill asks your agent to install it when it is missing (`npx skills add allyhub-ai/skills --skill allyhub -g`). In Claude Code or Codex, Node.js 22.19 or newer. AllyHub Studio brings everything.

### Is it free?

The skills are free (MIT) and AllyHub runs on your computer for free. AllyHub's cloud tools, such as generated voices, music, footage and research, use credits from an AllyHub account.
